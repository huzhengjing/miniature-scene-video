# 微缩三渲二场景视频

以真实三维几何搭建紧凑、层次清楚的微缩景观。支持文字与参考图，保持干净材质、明确轮廓、世界空间阴影和生活化动作。使用通用绘制引擎、按需获取的 Polyfork 素材与定制几何生成场景。

## 输出与执行规则

- 静帧和最终视频统一为 960×540。视频固定 24fps。每帧只调用一次时间采样，不进行四次抖动采样或自适应运动模糊采样。
- 每次授权范围内，静帧只出一批，成片只出一版。自检发现问题只报告，并说明影响和可改方向，是否修改与重渲由用户决定。失败也应保留计时和错误信息，重试交由用户决定。通过换文件名规避此规则也不允许。
- 用户要求先看样帧时，默认从同一批输出中选择四张关键帧拼图，交付后等候确认。用户另有指定时遵从其要求。已授权直接成片时执行该范围内工作。
- 默认使用 Windows Chrome，启动参数为 `--use-angle=d3d11`。删除 `--disable-gpu`，pixelRatio 与 deviceScaleFactor 均为 1。阴影贴图固定为 1024×1024。
- 保留颜色、法线与深度、反照率、阴影及后处理各通道，保留现有轮廓、色阶、世界空间排线和克制泛光。颜色通道已有的帧内 MSAA 与时间采样分别处理，保留帧内 MSAA。
- 每次真实渲染自动记录加载、出帧、抓帧、编码和总耗时，输出 JSON 与控制台汇总。计时随真实任务完成，单独测速需要用户要求。
- 保存到用户指定目录。技能包内不写死个人电脑路径。外部账号登录、付费和对外发送操作仍依用户授权。

## 场景搭建

1. 提取主体、场地比例、视角、材质色彩、时间氛围、动作事件和镜头限制。参考图先观察后搭建，可见结构优先，遮挡面的补全应向用户说明。沿用已有明确要求，缺失的可逆细节自行合理确定。
2. 阅读 [素材与搭建说明](references/authoring.md)，复制 `assets/illustration-engine.mjs`、`assets/lighting.mjs` 和 `assets/LICENSE.simcraft` 到项目。编写场景与相机模块，复用绘制引擎。运行依赖安装在场景项目中，技能包只保留必要源码。
3. 优先按需搜索并获取合适的 Polyfork GLB。保持比例、节点枢轴、顶点颜色和署名。地面、场线、建筑补全等适合参数化的内容直接生成几何。缓存实际使用的素材与元数据，避免下载整站素材库。授权及接口细节见搭建说明。
4. 静态场景使用固定种子。动画只由绝对时间计算，每次调用都能独立恢复人物、球、相机和道具状态。人物有真实位置移动及步态，道具交接使用连续世界空间轨迹。禁止以原地蹦跳代替跑动。主体比例与动作必须服务当前场景。
5. 默认连续镜头，镜头轨迹按场景及用户要求编写。采用参考技能的运动思路时保留当前场景的构图与空间约束。缓入缓出，重点动作与推进到位时间对应。需要循环时，场景状态、镜头和音轨在循环边界衔接。
6. 太阳主光位置、方向和太阳几何在世界坐标锁定。机位共用同一套灯光。太阳自然出画，静态物体阴影在场地上的落点固定。近景补亮使用全局环境光或半球光。通道内部为生成阴影遮罩使用的光强变化仅属于画法处理。
7. 根据用户要求合成音乐，默认轻柔五声音阶纯配乐。篮球场案例不添加拍球声。环境声与事件音仅在用户要求时加入并对齐时间轴。避免覆盖用户已有音轨。

## 渲染入口

场景项目安装 `three@0.170.0`、`playwright@1.60.0`，本机提供 Chrome、Node.js 与 ffmpeg。`CHROME_PATH` 和 `FFMPEG` 可指定可执行文件。依赖缺失时使用已有授权完成安装，实际权限问题按工具要求处理。

场景暴露 `window.READY`、`window.render(ms)`。相机与动作全部在此调用中完成，禁止依赖实时播放推进状态。渲染器只加载页面一次，逐帧读取，JPEG 在内存中送入 ffmpeg，静帧使用 PNG。无需视频逐帧 PNG 落盘。

```powershell
node "<skill>/scripts/render.mjs" "<project>/scene.html" "<project>/stills" --stills --times=0,4.5,18.5,24.8
node "<skill>/scripts/render.mjs" "<project>/scene.html" "<project>/film.mp4" --duration=32 --audio="<project>/music.wav"
```

示例时间点应按当前故事选择。截图自检使用本批输出，成片自检使用本版输出，问题形成简短报告，执行一次授权只出一版的规则。
